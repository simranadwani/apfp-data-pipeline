APFP Looker Studio calculated fields (paste-safe copy of Section 4 and Appendix C)
Straight quotes only. Create each field in the data source named in its heading.

NAMING (v0.1.11, see docs/LOOKER_FIELD_NAMING.md): the field name says what it is.
  distinct_*  COUNT_DISTINCT    sum_*  SUM    max_*  MAX    avg_*  per-unit average/ratio of sums
  pct_*       percentage        inr_*  rupee text (Indian grouping)   txt_*  text   ord_*  sort helper   link_*  hyperlink
Removed as unused (v0.1.11): m_committed, m_disbursed, m_apfp_share, m_team_size, m_attrition, m_foreign_share,
core_policies_text (4.02 now reads fct6), fy_label (the pipeline's financial_year is already "FY 26-27"),
recommendation_copy (3.06 is single-series), m_support_grantees.
Financial year charts and axes use financial_year (current-year source) or financial_year_all (all-years copy) directly.

DATA SOURCE: fct1_grant_portfolio  (fields marked "all-years copy" in Section 4 also go into "fct1_grant_portfolio (all years)")

Field name : distinct_active_orgs
Type       : Number
Display    : Active grantees
Used by    : 1.01, 1.07, 1.16 (all-years copy too)
Formula    : COUNT_DISTINCT(CASE WHEN is_active_grant THEN organization_id END)

Field name : distinct_active_grants
Type       : Number
Display    : Active grants
Used by    : 1.05, 1.06
Formula    : COUNT_DISTINCT(CASE WHEN is_active_grant THEN grant_id END)

Display    : On-track active grants
Used by    : 1.02
Formula    : COUNT_DISTINCT(CASE WHEN is_on_track_active_grant THEN grant_id END)

Field name : distinct_off_track_grants
Type       : Number
Display    : Off-track active grants

Display    : Active grantees on track

Field name : ord_funding_range
Type       : Number (dimension)
Display    : (sort key, hidden)
Used by    : 2.07 sort
Formula    : CASE WHEN funding_range = "<₹1 lakh" THEN 1 WHEN funding_range = "₹1–10 lakh" THEN 2 WHEN funding_range = "₹11–20 lakh" THEN 3 WHEN funding_range = "₹21–50 lakh" THEN 4 WHEN funding_range = ">₹50 lakh" THEN 5 ELSE 6 END

Field name : ord_due_window
Type       : Number (dimension)
Display    : (sort key, hidden)
Used by    : 3.05 sort
Formula    : CASE WHEN due_window = "Overdue" THEN 1 WHEN due_window = "0–30 days" THEN 2 WHEN due_window = "31–60 days" THEN 3 WHEN due_window = "61+ days" THEN 4 ELSE 5 END

Field name : txt_due_date
Type       : Text (dimension)
Display    : Due date

Field name : link_grantee_360
Type       : Text (dimension)
Display    : Grantee 360 link
Used by    : 3.07. Field name : txt_grant_period
Type       : Text (dimension)  [fct1_grant_portfolio]
Display    : Grant period
Used by    : 4.01 (GRANT PERIOD). The pipeline column grant_period is text ("2026-04-01 - 2027-03-31") but Looker Studio types it as a Date and shows only the start; this field shows both dates.
Formula    : CONCAT(FORMAT_DATETIME("%d %b %Y", grant_start_date), " – ", FORMAT_DATETIME("%d %b %Y", grant_end_date))
