APFP Looker Studio calculated fields (paste-safe copy of Section 4 and Appendix C)
Straight quotes only. Create each field in the data source named in its heading.

NAMING AND CONSOLIDATION (v0.1.12, see docs/LOOKER_FIELD_NAMING.md)
  RULE: one metric per meaning. Context (active, pending, open, Education ...) comes from a CHART-LEVEL FILTER, never from a new field.
  Plain sums and maxima use the built-in Sum / Max of the column (no calculated field). A calculated field exists only for ratios,
  text formatting (Indian rupee grouping), multi-term formulas and sort helpers.
  Prefixes: distinct_ COUNT_DISTINCT   sum_ SUM   avg_ per-unit ratio   pct_ percentage   inr_ rupee text   txt_ text   ord_ sort helper   link_ hyperlink
  Core metrics: distinct_grantees, distinct_grants, distinct_needs (the same field name and formula in every data source that has the column).
  Removed in v0.1.12 because a core metric + chart filter or the built-in Sum replaces them: all other distinct_* counts, sum_beneficiaries, sum_approved,
  sum_proposed, max_annual_budget, sum_proposed_renewal, sum_disbursed_lakh_if_different, pct_annual_achievement, the fct4 sum_* helpers,
  inr_proposed_renewal, ord_aspect (the pipeline now provides aspect_order and status_order in fct5).
  Removed in v0.1.11: m_committed, m_disbursed, m_apfp_share, m_team_size, m_attrition, m_foreign_share, core_policies_text, fy_label, recommendation_copy, m_support_grantees.
  Looker Studio syntax in THIS report (v0.1.13, matches the live fields): the is_* flags are text, so compare them as is_x = "TRUE";
  ROUND takes two arguments, ROUND(x, 0). The rupee formulas were re-tested for 0, 960, 96000, 750000, 8600000, 98000000 and -9675000.
  Financial year charts and axes use financial_year (current-year source) or financial_year_all (all-years copy) directly.

Field name : pct_active_grants_on_track
Type       : Percent
Display    : Active grantees on track
Used by    : 1.02
Formula    : CASE WHEN COUNT_DISTINCT(CASE WHEN is_active_grant = "TRUE" THEN grant_id END) = 0 THEN NULL ELSE COUNT_DISTINCT(CASE WHEN is_on_track_active_grant = "TRUE" THEN grant_id END) / COUNT_DISTINCT(CASE WHEN is_active_grant = "TRUE" THEN grant_id END) END

Field name : distinct_grantees
Type       : Number
Display    : Grantees
Used by    : 1.01 (+ filter is_active_grant), 1.07 (+ is_active_grant), 1.08 (+ thematic_area = Education), 1.10, 1.16 (+ is_active_grant, all-years copy too), 2.07 (+ is_funded_grantee)
Formula    : COUNT_DISTINCT(organization_id)

Field name : distinct_grants
Type       : Number
Display    : Grants

Field name : ord_funding_range
